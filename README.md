# Radh Shahmat - Portfolio

Static site: open `index.html`, or upload the folder to GitHub Pages / Vercel / Netlify (no build step).

- Cube-name intro: `assets/js/intro.js` + `assets/css/intro.css` (WebGL, with a CSS fallback). Skip it while editing with `index.html?intro=0`.
- Projects (four animated films with a soundtrack): `assets/js/projects.js`, `assets/css/projects.css`, films and posters in `assets/video/`, stills in `assets/img/`. Project links live in the `FILMS` object at the top of `projects.js` and in the section markup in `index.html`.
- Everything else (colours, hero, About, Research, Skills, Contact): `css/style.css` and `js/main.js`.
- CV: `Radh_Shahmat_Resume.pdf` (site root). To replace it later, keep the same name and bump `?v=2` to `?v=3` in the three Download CV links.
